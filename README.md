# 🛡️ AI-Powered Code Quality & Security Analyzer

## 📌 Project Overview

AI-Powered Code Quality & Security Analyzer is a tool that analyzes Python code and identifies common code quality problems and security risks.

It provides quality and security scores along with suggestions to improve the code.

---

## 🎯 Problem Statement

Developers can make coding mistakes that may reduce code quality or create security vulnerabilities.

Our project helps developers detect common issues early by automatically analyzing their code.

---

## ✨ Features

- 💻 Python code input
- 🔍 Code quality analysis
- 🔐 Security vulnerability detection
- 📊 Code quality score
- 🛡️ Security score
- 🏆 Overall code score
- ⚠️ Issue detection
- 💡 Improvement suggestions
- 🌐 Simple web-based interface

---

## 🧠 How It Works

The system follows these steps:

1. User enters Python code.
2. The analyzer checks the code.
3. Quality-related problems are detected.
4. Common security risks are detected.
5. Scores are calculated.
6. Results and suggestions are displayed.
